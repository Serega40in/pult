# PULT Lite — управление Chrome из чата ChatGPT

Минимальная версия PULT для одной задачи: прочитать выбранную вкладку Chrome и выполнять ограниченные команды из специального блока PULT в ответе ChatGPT.

**Локальный режим не требует Python, Node.js, API-ключей или сервера.** Дополнительно доступен режим PULT API на PHP + MySQL.

## Установка в Chrome

1. Скачай ZIP с PULT Lite и распакуй его в отдельную папку.
2. Открой chrome://extensions.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение».
5. Выбери папку extension из распакованного архива.
6. Закрепи PULT на панели Chrome, открой ChatGPT в этой же версии Chrome и обнови вкладку ChatGPT.

Никаких команд в терминале выполнять не нужно. При изменении файлов расширения нажми «Обновить» на карточке PULT в chrome://extensions.

## Как работать

1. Открой нужный сайт в отдельной вкладке Chrome.
2. Открой ChatGPT в другой вкладке.
3. Нажми значок PULT и выбери вкладку, которой нужно управлять.
4. Попроси ChatGPT выполнить действие. Когда я подготовлю специальный блок с языком pult, под ним появится кнопка «Выполнить в PULT».
5. Проверь план и нажми кнопку. Результат появится под блоком.
6. Нажми «Добавить результат в чат», затем сам отправь результат сообщением. Я увижу, что реально произошло, и смогу подготовить следующий шаг.

Также в окне расширения есть кнопка «Прочитать страницу» — она собирает видимый текст выбранной вкладки. Скопируй его и вставь в чат.

## Команды

Поддерживаются: navigate, read_page, click, type, scroll и wait. Один план может содержать до 8 шагов.

## Подключение PULT API (необязательно)

В версии 0.3 можно подключить собственный PHP API, чтобы вести очередь заданий и сохранять результаты.

1. Разверни `server/php-api` на HTTPS-хостинге по инструкции в [server/php-api/README.md](server/php-api/README.md).
2. Создай базу MySQL, импортируй `schema.sql`, скопируй `config.example.php` в `config.php` и заполни настройки на сервере.
3. Добавь точный ID расширения из `chrome://extensions` в `allowed_origins` файла `config.php`.
4. Открой окно PULT, укажи адрес вида `https://your-domain/pult-api`, название устройства и pairing secret из серверной конфигурации.
5. Нажми «Подключить API». Секрет используется только для первичной регистрации; постоянный токен устройства хранится локально в `chrome.storage.local`.

После подключения кнопка выполнения в блоке `pult` сначала создаёт задание в API, подтверждает его нажатием пользователя, получает задание, выполняет его в выбранной вкладке и сохраняет результат на сервере. Если API не подключён, расширение продолжает работать в прежнем локальном режиме.

**Важно:** исходники API подготовлены, но сервер ещё не развёрнут на Reg.ru и не проверен с реальной базой данных. Не включай подключение, пока не завершена установка по инструкции.

## Ограничения первой версии

- Это расширение Chrome, а не полноценный MCP-плагин. В локальном режиме оно выполняет команды из формата ответа ChatGPT после нажатия. В API-режиме дополнительно сохраняет задания и результаты на собственном сервере; это само по себе не подключает сервер к ChatGPT как инструмент.
- Нужен Chrome или совместимый браузер Chromium.
- Команды выполняются только после нажатия пользователем.
- Отправка HTML-форм, произвольный JavaScript, запуск команд Windows, чтение cookies, local storage, паролей и платёжных реквизитов не поддерживаются.
- Прокрутка, чтение страницы, переход по URL, обычные клики и заполнение текстовых полей ограничены проверками.
- Селекторы и расположение элементов сайтов могут меняться.
- Расширение не управляет вкладками chrome://, страницами расширений и другими системными страницами браузера.

## Приватность

Исходный код не содержит внешнего сервера, телеметрии, аналитики или отправки содержимого вкладок сторонним сервисам. Текст страницы передаётся в ChatGPT только тогда, когда ты сам копируешь и отправляешь его.
