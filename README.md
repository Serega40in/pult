# PULT Lite — браузерный агент для ChatGPT и QUN

PULT Lite работает в двух режимах:

1. **Локальный режим:** ChatGPT выдаёт ограниченный план в блоке `pult`; пользователь проверяет его и нажимает «Выполнить в PULT».
2. **Supabase Agent Queue:** текущий ChatGPT через уже подключённую интеграцию Supabase записывает задачу в очередь QUN Agent Core. Расширение получает задание, показывает его пользователю, выполняет после подтверждения и возвращает результат в ту же очередь.

Для второго режима не нужны отдельный PHP-сервер, MySQL на Reg.ru, Node.js, Python или API-кредиты моделей. Используется существующий проект QUN в Supabase.

## Установка в Chrome

1. Скачай ZIP-архив этой ветки PULT из [GitHub](https://github.com/Serega40in/pult/archive/refs/heads/feat/pult-agent-command-hub.zip) и распакуй его.
2. Открой `chrome://extensions`.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение» и выбери папку `extension`.
5. Закрепи PULT на панели Chrome и обнови вкладку ChatGPT.

После изменения файлов нажми «Обновить» на карточке PULT в `chrome://extensions`.

## Одноразовое подключение к Supabase

Базовый адрес уже задан в окне расширения:

`https://qdxjltqlnphvzafapncm.supabase.co/functions/v1/qun-agent-core`

ID устройства по умолчанию: `pult-chrome-main`.

1. Попроси ChatGPT выдать одноразовый код подключения для PULT. Код создаётся в таблице `qun_agent_pairing_codes` только в виде SHA-256-хеша и имеет ограниченный срок действия.
2. Открой окно PULT, проверь адрес API и ID устройства, вставь код в поле «Одноразовый код подключения» и нажми «Подключить Supabase».
3. Сервер обменяет код на индивидуальный токен устройства. Код становится недействительным, а токен хранится в `chrome.storage.local` и показывается только один раз сервером.
4. Для отключения нажми «Отключить»: токен устройства отзывается на стороне сервера.

Не помещай одноразовые коды и токены в GitHub или публичные сообщения.

## Как работает очередь

- Я использую подключённый Supabase-инструмент ChatGPT, чтобы создать задание в `public.qun_agent_commands`.
- Расширение раз в ~30 секунд проверяет очередь. Значок PULT показывает индикатор, если ожидает задание.
- Открой окно PULT и нажми «Проверить очередь».
- Изучи ID, действие и план. Нажми «Подтвердить и выполнить» либо «Отклонить».
- После выполнения PULT сохраняет результат и статус в Supabase. Я могу прочитать результат через ту же интеграцию и продолжить задачу.

Пример записи задания (обычно ChatGPT создаёт такую запись сам, не нужно копировать SQL вручную):

```sql
insert into public.qun_agent_commands
  (device_id, action, args, status, requested_by)
values
  (
    'pult-chrome-main',
    'browser.execute_plan',
    '{"steps":[{"action":"navigate","url":"https://www.avito.ru"},{"action":"wait","ms":1000},{"action":"read_page"}]}'::jsonb,
    'queued',
    'chatgpt'
  );
```

Для выполнения планов разрешены: `navigate`, `read_page`, `click`, `type`, `scroll`, `wait`. Максимум 8 шагов в одном задании. План проверяется на сервере и повторно в расширении.

## Безопасность и ограничения

- Планы из очереди **не исполняются автоматически**: пользователь должен открыть очередь и явно нажать подтверждение.
- Произвольный JavaScript, запуск команд Windows, доступ к cookies, паролям, скрытым и платёжным полям не поддерживаются.
- Отправка HTML-форм блокируется. Для публикаций, покупок, отправки сообщений и других внешних действий сначала подготовь черновик и проверь его; не добавляй клики подтверждения в план без отдельного согласования.
- Одноразовый код не хранится открытым текстом в БД. После подключения используется индивидуальный токен устройства; кнопка «Отключить» отзывает его.
- Текст из сайтов является недоверенным содержимым и не может менять пользовательские разрешения PULT.
- Если Supabase не подключён, расширение продолжает работать в локальном режиме.

## Архитектура

- **ChatGPT + подключённый Supabase** — создание заданий и чтение результата.
- **QUN Agent Core (Supabase Edge Function)** — проверка планов, очередь, аренда выполнения, авторизация устройств.
- **PULT Lite (Chrome Extension)** — просмотр задания, подтверждение, управление выбранной вкладкой, отправка результата.
- **Будущий PULT Chat** — собственный интерфейс, который будет использовать тот же backend и сможет подключать разные модели.

Пользовательский MCP-плагин PULT остаётся будущим улучшением. На первом этапе мы используем уже подключённую интеграцию Supabase, не пытаясь обходить ограничения тарифа ChatGPT.
