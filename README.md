# PULT — AI Remote Control Panel (Browser + Desktop)

**PULT** (пульт) — простой локальный «пульт» для управления браузером и (ограниченно) компьютером с помощью планов, которые составляют Grok, GPT, Claude или Gemini.

Ничего не выполняется автоматически. AI только предлагает план в виде JSON. Вы сами нажимаете «Выполнить».

## Что умеет

### 1. Расширение для Chrome / Edge (браузер)
- Открыть URL
- Кликнуть по селектору
- Ввести текст в поле
- Прокрутить страницу
- Пауза

Работает **только на активной вкладке**. Пароли, cookies и чувствительные данные не трогает.

### 2. Desktop Agent (Python, локально)
- Открыть URL в браузере по умолчанию
- Открыть приложение
- Напечатать текст (pyautogui)
- Нажать горячие клавиши
- Показать уведомление
- Пауза

**Важно:**
- Работает только на **вашем** компьютере.
- AI в облаке **не имеет** прямого доступа к вашему компьютеру или телефону.
- Чтобы «управлять через API», вы сами запускаете агента локально и передаёте ему план.

### 3. Телефон
Полноценное удалённое управление телефоном из этого репозитория **не реализовано** (и небезопасно).  
Можно вручную:
- Ставить виджеты / Shortcuts (iOS) / Tasker (Android)
- Использовать черновики сообщений и напоминания, которые вы отправляете сами.

## Установка расширения

1. Скачайте репозиторий (Code → Download ZIP) или клонируйте.
2. Распакуйте.
3. Откройте `chrome://extensions` (или `edge://extensions`).
4. Включите «Режим разработчика».
5. «Загрузить распакованное расширение» → выберите папку `extension`.

После установки:
- Откройте любую вкладку.
- Нажмите на иконку PULT.
- Вставьте JSON-план (или нажмите «Пример»).
- Нажмите «Выполнить план».

## Установка Desktop Agent

```bash
cd desktop
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install pyautogui
python agent.py --plan example_plan.json
```

Пример плана (`example_plan.json`):

```json
{
  "steps": [
    { "action": "notify", "title": "PULT", "message": "Начинаю" },
    { "action": "open_url", "url": "https://example.com" },
    { "action": "wait", "ms": 2000 },
    { "action": "hotkey", "keys": ["command", "t"] }
  ]
}
```

## Как использовать с ИИ (Grok / GPT и др.)

1. Опишите задачу ИИ, например:
   > Составь JSON-план для PULT Browser Agent: открыть Google, ввести «погода Москва», нажать Enter.

2. ИИ выдаёт что-то вроде:
```json
{
  "steps": [
    {"action": "navigate", "url": "https://www.google.com"},
    {"action": "wait", "ms": 1500},
    {"action": "type", "selector": "textarea[name=q]", "text": "погода Москва"},
    {"action": "hotkey", "keys": ["enter"]}
  ]
}
```
(для расширения формат чуть другой — см. popup)

3. Вы копируете JSON в расширение или в `agent.py` и сами запускаете.

### Подключение через PULT Bridge (экспериментальная версия)

В ветке `feat/pult-bridge-mvp` добавлен локальный Bridge:
- FastAPI сервер на `127.0.0.1:8765`;
- WebSocket-канал между сервером и расширением;
- REST API с автоматически создаваемой OpenAPI-схемой;
- локальный MCP-адаптер через stdio для совместимых ИИ-клиентов.

Инструкция по установке и подключению: [bridge/README.md](bridge/README.md).

Bridge пока управляет браузером. Интеграция Desktop Agent и локальное окно подтверждения рискованных действий запланированы следующим этапом. Это экспериментальная ветка — сначала проверьте подключение и работу на тестовых страницах.

## Ограничения и безопасность

- Расширение не имеет доступа к другим вкладкам без вашего действия.
- Desktop-агент использует `pyautogui.FAILSAFE` — отведите мышь в угол экрана, чтобы прервать.
- Никогда не запускайте планы, которые просят вводить пароли, отправлять деньги, удалять файлы и т.п.
- Телефон: только через официальные средства автоматизации (Shortcuts / Tasker) и только действия, которые вы подтверждаете.
