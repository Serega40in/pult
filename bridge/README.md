# PULT Bridge (MVP)

PULT Bridge connects the existing browser extension to local automation clients.

## Architecture

- `server.py`: authenticated FastAPI service, bound to `127.0.0.1`.
- Extension background worker: makes an outbound WebSocket connection to the local service.
- `mcp_server.py`: stdio MCP adapter for compatible local AI clients.
- REST API and generated OpenAPI schema: `http://127.0.0.1:8765/docs` and `/openapi.json`.

The browser extension stays the only component that touches the browser. The bridge never accepts JavaScript source code; it validates a short allowlist of actions.

## Requirements

- Python 3.10+
- Chrome or Edge with the unpacked extension loaded
- Windows, macOS, or Linux

## 1. Install the extension

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this repository's `extension` folder.
4. Copy the extension ID shown on the extension card.
5. Open the PULT extension on the tab you want to control. The click grants the browser's temporary `activeTab` access.

The extension requests additional host access only when the user clicks **Allow access to this site** in the popup.

## 2. Start the local bridge (PowerShell)

From the repository root:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r bridge/requirements.txt

$env:PULT_API_TOKEN = "replace-with-a-long-random-api-token"
$env:PULT_EXTENSION_TOKEN = "replace-with-a-different-long-random-extension-token"
$env:PULT_EXTENSION_ID = "paste-extension-id-here"

py -m uvicorn bridge.server:app --host 127.0.0.1 --port 8765
```

Generate both tokens locally with a password manager or a cryptographically secure random generator. Do not use the same token for the API and the browser extension.

For macOS/Linux, export the same three environment variables before running:

```bash
python -m pip install -r bridge/requirements.txt
export PULT_API_TOKEN='...'
export PULT_EXTENSION_TOKEN='...'
export PULT_EXTENSION_ID='...'
python -m uvicorn bridge.server:app --host 127.0.0.1 --port 8765
```

## 3. Pair the extension

1. Open the PULT extension popup.
2. Open **Bridge settings**.
3. Paste the value of `PULT_EXTENSION_TOKEN` and save.
4. Check that the popup reports the bridge connection as active.
5. On the site you want to control, click **Allow access to this site** if browser permissions are requested.

The API token is used by local AI connectors and is not stored in the extension.

## 4. Connect a local MCP client

The MCP adapter uses standard input/output (stdio). Example Claude Desktop configuration:

```json
{
  "mcpServers": {
    "pult": {
      "command": "C:\\path\\to\\pult\\.venv\\Scripts\\python.exe",
      "args": ["C:\\path\\to\\pult\\bridge\\mcp_server.py"],
      "env": {
        "PULT_API_TOKEN": "your-api-token",
        "PULT_BASE_URL": "http://127.0.0.1:8765"
      }
    }
  }
}
```

Restart the MCP client after saving its configuration. The available tools are:

- `pult_status`
- `pult_browser_read_page`
- `pult_browser_navigate`
- `pult_browser_click`
- `pult_browser_type`
- `pult_browser_scroll`

## 5. API endpoints

- `GET /health` — basic process health (no secrets returned).
- `GET /v1/status` — bridge and extension connection state; requires Bearer token.
- `POST /v1/browser/execute` — execute a validated browser plan; requires Bearer token.
- `GET /openapi.json` — OpenAPI description generated by FastAPI.

Example:

```bash
curl http://127.0.0.1:8765/v1/status \
  -H "Authorization: Bearer $PULT_API_TOKEN"
```

## Security notes and known MVP limits

- The server binds to loopback only. Do not change this to `0.0.0.0` or expose port 8765 directly to the Internet.
- The extension validates the WebSocket Origin against `PULT_EXTENSION_ID` and authenticates separately with `PULT_EXTENSION_TOKEN`.
- The API requires `PULT_API_TOKEN`; keep it in the connector's local environment, never in prompts or source control.
- The extension uses optional website permissions. A user must grant access to the site before page interaction; `activeTab` access is initially granted by opening the extension popup on the target tab.
- Browser text can contain private information. Read-page output is returned to the connected AI client only when requested.
- This MVP has no local approval dashboard yet. Treat click and type tools as write-capable and configure the AI client to ask before each action. Do not use them for passwords, financial actions, account security settings, deletion, or other irreversible operations.
- Desktop control is not exposed through this first Bridge MVP. The existing `desktop/agent.py` remains separate until we add a local approval screen and per-action policy.
- ChatGPT connects to remote HTTPS MCP services, not a plain localhost stdio server. A future ChatGPT setup needs a secure MCP tunnel/remote endpoint. Full write-capable custom MCP apps are currently limited by ChatGPT plan and workspace availability; test read-only connectivity first.
